# Google Sign-In setup for LoopKeeper

The Google button works only with a real OAuth 2.0 **Web application** Client ID.
A fake or deleted Client ID produces Google's **Error 401: invalid_client / OAuth client was not found** page.

## 1. Create/configure the Google OAuth client

1. Open Google Cloud Console and select or create your project.
2. Configure the Google Auth Platform branding/consent screen.
3. Create an OAuth Client ID.
4. Choose **Web application**.
5. Add these **Authorized JavaScript origins** for local development:
   - `http://127.0.0.1:8000`
   - `http://localhost:8000`
6. For PythonAnywhere, add your real deployed site origin, for example:
   - `https://YOUR_USERNAME.pythonanywhere.com`
7. Save and copy the generated **Client ID**. It ends with `.apps.googleusercontent.com`.

LoopKeeper uses Google Identity Services to obtain an ID credential in the browser and verifies that credential on the FastAPI server. It does not require the Client Secret for this sign-in flow.

## 2. Configure LoopKeeper locally

Create a `.env` file beside `main.py`:

```env
GOOGLE_CLIENT_ID=PASTE_THE_REAL_CLIENT_ID_HERE.apps.googleusercontent.com
LOOPKEEPER_UPLOAD_DIR=uploads
LOOPKEEPER_MAX_UPLOAD_BYTES=26214400
```

Then fully stop and restart the server. Do not rely on hot reload after changing `.env`.

## 3. Verify before GitHub

Run the application and open:

`http://127.0.0.1:8000/api/auth/google/config`

Expected result:

```json
{"enabled": true, "client_id": "...apps.googleusercontent.com", "message": "Google Sign-In is ready"}
```

If `enabled` is `false`, the browser intentionally does not render a Google button, preventing the invalid-client page.

## 4. Configure PythonAnywhere

Store `GOOGLE_CLIENT_ID` as an environment variable or in the deployment `.env` file that is **not committed to GitHub**. Add the exact HTTPS PythonAnywhere origin to the same Google OAuth Web Client.

After deployment, reload the web app from the PythonAnywhere Web tab and test `/api/auth/google/config` again.

## Security checklist

- Never commit `.env`.
- Never commit an OAuth client secret.
- Use the exact real Client ID generated by Google.
- Keep local and production origins registered separately.
- If Google still says "OAuth client was not found", create a new Web application OAuth client and replace the Client ID.
